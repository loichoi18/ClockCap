    What this is. The agents are the Q-learning, DQN and PPO policies trained on the real RTX 3080. Here they control a simulator built from the speed and power profile we measured on that GPU for each Qwen 2.5 model, so the demo runs anywhere without a GPU. The left lane always runs at driver default and the right lane follows the agent, with the same request stream and the same random seed. One step is one second of serving, as in training. The simulator is optimistic about latency (for 1.5B without RL: 99.6% on target in simulation against 96.2% measured), so use the measured replay and the report for final numbers. "Latency target" changes the targets both lanes are judged against; the agents were trained at the middle setting.
